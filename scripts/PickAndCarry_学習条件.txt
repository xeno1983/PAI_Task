Pick-and-Carry 学習条件
更新: 2026-10-18

この文書は、いま走らせている学習が何を前提にしているかをまとめたものです。
数値は pick_and_carry/config.py と環境の実装に合わせています。
提出用スライドは scripts/make_summary_slide.py、提出動画は scripts/make_presentation.py が生成します。


1. 環境条件
----------------------------------------------------------------

シミュレータ
  Genesis 1.4.3、GPU（この PC は RTX 5070 Laptop、約 8 GB）。
  制御周期 dt = 0.02 秒（50 Hz）。
  エピソードは最長 20 秒（1000 ステップ）。
  確認は録画 mp4（起動スクリプトのメニュー）を使う。

ロボット
  Unitree Go2 の脚 12 関節に、Unitree Z1（6 DoF + グリッパ）を載せた一体モデル。
  URDF は assets/urdf/quadruped_z1.urdf。
  自己衝突はオフ。位置制御（PD）。
  脚 kp 60 / kd 1.5、腕 kp 80 / kd 8、指 kp 20 / kd 2。

観測は 81 次元。ノイズも遅れも無い（キャッチの noisy 段階だけ観測にノイズ）。
行動は 17 次元（おおよそ -1〜1）
  CPG パラメータ 10、腕 6、指 1。
  脚の 12 関節指令は環境内の対角トロット CPG（pick_and_carry/cpg.py）が展開する。
  CPG は振幅・周波数・デューティ相当・姿勢バイアス・横方向・ヨー・旋回などを学習する。
  歩行では腕は方策外（固定またはランダム保持）。
  reach / haul / carry / catch では腕は数値 IK のベース姿勢に小さな残差（×0.12 rad）を足す。
  指は段階ベースの開閉に残差（×0.35 rad）。方策出力は Δq / Δg のまま。
  BC / GAIL / PPO はいずれもこの 17 次元を共有する。旧 19 次元（脚 12 直接）や旧・腕フル指令の重みは使えない。

段階（箱運び）
  0  箱へ歩く / 1  拾う / 2  運ぶ / 3  置く
  転倒は傾き過大、またはベース高さ不足。


2. 学習している内容
----------------------------------------------------------------

アルゴリズム
  強化学習: PPO（ほか GRPO / Symmetric PPO も選択可）。
  模倣: 教師 CPG → Behavioral Cloning、および GAIL。
  ネットワークは隠れ層 512×256×128、活性化 ELU。方策は対角正規分布。

方策が決めるもの
  歩行段階: CPG パラメータのみ（腕は環境が固定またはランダム保持）。
  操作を含む段階: CPG + 腕 + 指。

報酬の主なもの
  歩行は指令速度への一致（legged_gym 系）。
  箱運びは前進・接近・把持・運搬・設置、転倒罰。
  到達・キャッチは手先の接近・速度一致・保持。


3. 事前に使っているもの
----------------------------------------------------------------

学習済みの外部歩行モデルは使っていない。
歩行の暖機には開ループ CPG 教師（TrotTeacher）のデモと BC / GAIL を使える。
  easy-walk で PPO チェックポイントが無いとき、train_ppo は gail_trot.pt → bc_trot.pt の順で自動初期化する
  （--init-from 未指定時。起動スクリプトと同じ順）。


4. 段階的な学習
----------------------------------------------------------------

起動スクリプトの学習で次の段階を選ぶ。全段階が観測 81・行動 17 なので重みを引き継ぐ。

  1. 歩行（walk）。平地から地形へ。logs/{algo}_curriculum_walk[_easy]
  2. 到達（reach）。歩行の重みから。
  3. 歩きながら持つ（haul）。到達から。
  4. 箱運び（carry）。持ち歩きから。logs/{algo}_z1
  5. キャッチ（catch）。到達から。static → slow → random → fly → noisy

模倣学習（メニュー 1）は easy-walk フォルダに教師 / BC / GAIL の重みを残し、
動画は次のサブフォルダへ分ける（上書きしない）:

  logs/.../videos/<タスク>/<種別>_ep####_iter######_<時刻>/
    例) videos/walk_easy/bc_ep0080_20261018-153012/bc_trot_demo.mp4
    例) videos/walk_easy/gail_iter000300_20261018-154500/gail_trot_demo.mp4
    例) videos/carry/ppo_iter002000_20261018-160000/PickAndCarry_ppo_z1.mp4

提出動画（メニュー 6）はスライドと、これらのデモおよび各段階の録画をつなぐ。


5. 提出物の作り方
----------------------------------------------------------------

  スライド: python -u scripts/make_summary_slide.py
    → Desktop/起動スクリプト/PickAndCarry/PickAndCarry_学習条件.pptx
  提出動画: python -u scripts/make_presentation.py
    → 同フォルダの PickAndCarry_presentation.mp4（videos/ 以下も再帰検索）
  または起動スクリプトのメニュー 6。
